# MongoDB Fundamentals and CRUD Operations

## Project Overview
This repository contains my MongoDB practical work, covering database creation, collection management, CRUD operations, and query operators using MongoDB Shell (`mongosh`).

## Databases

### 1. Student Database (`studentDB`)
- Database and collection creation
- Inserting student records using `insertOne()` and `insertMany()`
- Retrieving documents using `find()` and `findOne()`
- Updating records using `updateOne()` and `updateMany()`
- Deleting records using `deleteOne()` and `deleteMany()`

### 2. Library Management System (`libraryDB`)
- Creating a books collection
- Inserting book records
- Searching books by availability and genre
- Updating book availability
- Deleting book records

## Query Operators
- Comparison: `$gt`, `$lt`, `$in`
- Logical: `$and`, `$or`
- Element: `$exists`

## Technologies Used
- MongoDB
- MongoDB Shell
- JavaScript
